# Analyst Studio Implementation Plan

**Goal:** Deliver the full upload → profile → clean → dashboard → export workflow.
**Architecture:** Pure service functions plus a per-session Reflex State. Pages use
shared card/table/field components and Tailwind classes. No persistent data store.
**Tech stack:** Reflex, pandas, DuckDB, Plotly, WeasyPrint, Matplotlib, Gemini SDK.
**Spec:** `docs/superpowers/specs/2026-09-18-analyst-design.md`

## Global constraints

- All authored frontend/backend logic is Python; responsive Tailwind via class_name.
- No real API keys, database, login, or browser persistence of application data.
- Dataframe changes require a preview, preserve input, support undo and clear AI.

## Tasks

- [ ] Data services: write tests in `tests/test_services.py` for `read_csv`,
  `profile`, `clean`, and `filter_frame`; run pytest to observe missing implementation;
  implement `services/data.py` and `services/cleaning.py`; rerun tests.
- [ ] Analytics/export: test `auto_charts`, `custom_chart`, `csv_bytes`, `excel_bytes`,
  `pdf_bytes`, and optional `generate_insight`; implement services with shared chart
  data and bounded summaries. Test actual PDF signature and text extraction.
- [ ] State: implement load/reset, two-phase preview/apply, full undo, reactive
  filters, async AI, and in-memory downloads; test changes and isolation using
  independently instantiated Reflex states.
- [ ] UI: implement shared components and five workflow views, dirty sample,
  validation feedback, busy states, empty states, history and export scope text.
- [ ] Integration: compile the actual Reflex page, run app, check user workflow
  and download outputs, document startup and configuration in README.

Verification commands: `.venv/bin/python -m pytest -q`,
`.venv/bin/python -m compileall -q analyst_studio rxconfig.py`, and a real Reflex
frontend compilation/startup. Git metadata in this workspace is an empty read-only
directory, so no branch creation or commits are attempted.
